# 家庭风险保障缺口分析与保单体检规划规范

## 1. 背景与目标
目前家庭保险管理系统具备完善的“保费支出账本与缴费日历”能力，但用户在家庭保障决策中面临的核心问题是：
- **保障到底够不够？**
- **家庭成员中是否存在风险裸奔或严重保障盲区？**
- **保费支出是否花在了刀刃上（杠杆率是否合理）？**

本规划旨在为系统构建**家庭风险保障诊断引擎（Policy Audit & Gap Analysis Engine）**，从“保费记账”跃升为“家庭风险防御导航”。

---

## 2. 核心功能架构设计

### 2.1 四大人身险种保障覆盖矩阵 (Coverage Matrix)
系统为每位家庭成员建立四维人身风险防御模型：
1. **重疾险（Critical Illness）**：
   - 核心指标：重疾确诊即赔保额（抵御收入损失、长期康复护理费）。
   - 细分维度：轻症/中症赔付比例、恶性肿瘤二次赔、少儿特疾翻倍。
2. **医疗险（Medical Expense）**：
   - 核心指标：百万医疗年度限额、免赔额（如1万元免赔 vs 0免赔）、报销比例（社保内外100%报销）。
   - 关键属性：质子重离子医院覆盖、特药/CAR-T责任、保证续保年限（20年/6年/1年）。
3. **寿险/定寿（Term Life）**：
   - 核心指标：身故/全残保额（覆盖家庭总负债、子女教育基金、父母赡养储备）。
   - 核心对象：家庭经济支柱（父母双亲优先，严禁为未成年人盲目购买高额定寿）。
4. **综合意外险（Accident）**：
   - 核心指标：意外身故/伤残保额、意外医疗保额（0免赔、不限医保目录）、猝死保障。

---

## 3. 保额缺口科学测算算法模型

系统将根据家庭财务画像自动测算建议保额（Benchmark），并与现有保额对比生成**缺口值（Gap）**：

### 3.1 经济支柱身故定寿测算（双十原则与负债覆盖法）
$$\text{建议定寿保额} = \text{家庭未还房贷与负债总额} + (\text{家庭年生活支出} \times 5 \text{年}) + \text{子女至大学毕业预估教育金} - \text{家庭高流动性金融资产}$$

### 3.2 重疾险保额测算（收入替代法）
$$\text{建议重疾保额} = (\text{个人年收入} \times 3 \sim 5 \text{年}) + \text{重大疾病平均康复治疗自费准备金 (约 20 \sim 30 万)}$$
* 成人建议底线：30万 ~ 50万
* 优质杠杆区间：50万 ~ 100万

### 3.3 医疗险与意外险底线
* 百万医疗险：家庭人手一份，重点评估是否拥有“保证续保 20 年”长期医疗。
* 意外险：成人意外身故保额不低于 100 万；老人重点看骨折医疗与意外医疗额度；少儿重点看烧烫伤与跌打损伤门急诊。

## 4. 界面与可视化展示规划

1. **家庭成员保障覆盖雷达图（Radar Chart）**：
   - 每位成员对应一个五维雷达图（重疾、医疗、寿险、意外、长期照护），直观呈现短板。
2. **家庭保障红黄绿健康评级（Traffic Light Audit）**：
   - **绿色（充足）**：已达推荐保额的 80% 以上。
   - **黄色（偏低）**：有基础保障但存在明显缺口（例如房贷 200 万但定寿仅 50 万）。
   - **红色（裸奔）**：某关键险种完全缺失。
3. **全家杠杆率统计卡片（Leverage Multiplier）**：
   - 计算公式：$\text{全家总风险杠杆保额} \div \text{历年累计已交总保费}$。
   - 直观展示几万元保费换取千万级风险护城河的高杠杆金融属性。
4. **一键生成「家庭保单体检报告」（PDF 导出）**：
   - 生成带图表与专业解读的 PDF 诊断报告，便于家庭内部会议讨论与年度保单复盘。

---

## 5. 后续演进路线
- **Phase 1**：保单金额结构化字段改造（增加明确的数字保额，拆分重疾/寿险/意外/医疗限额）。
- **Phase 2**：开发保障缺口分析视图（Radar Chart + 缺口诊断建议表）。
- **Phase 3**：家庭财务问卷联动（录入房贷、年支出，动态输出智能推荐保额）。
