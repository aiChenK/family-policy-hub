# 理赔全流程与历史赔付管理规划规范

## 1. 背景与目标
保险的核心价值体现在“出险时的兑现能力”。家庭在发生疾病住院或意外时，往往处于慌乱状态，容易遇到：
- **不知道该向哪家保险公司报案，报案时限超期**；
- **就医过程中未妥善保留关键单据（病历首页、费用总清单、医保结算单原件）导致理赔受阻**；
- **多份保单之间不知道报销顺序（如社保 -> 医保 -> 百万医疗 -> 意外医疗 -> 惠民保）**；
- **缺乏家庭历史获赔台账，无法复盘已缴纳保费的实际风险对冲效果**。

本规划旨在打造**家庭理赔全生命周期助手（Claims Management Hub）**。

---

## 2. 核心功能架构设计

### 2.1 理赔案卷数据模型 (Claim Case Schema)
每笔理赔建立独立案卷，包含如下核心实体：
* `id`: 理赔流水号（如 `CLM20260907001`）
* `member`: 出险人姓名
* `eventType`: 出险原因（意外门急诊 / 住院医疗 / 重疾初次确诊 / 身故全残 / 车辆碰撞）
* `eventDate`: 出险发生日期
* `hospital`: 就诊医院名称（区分二级及以上公立医院普通部 / 特需部 / 国际部）
* `diagnosis`: 医院诊断结果（如“急性阑尾炎微创手术”、“右踝骨折”）
* `associatedPolicies`: 关联报销保单列表（支持勾选当前成员名下有效的一张或多张保单）
* `status`: 理赔状态机
  - `reporting`: 已报案待提交材料
  - `submitted`: 材料已寄送/已上传，保司审核中
  - `investigating`: 保司核查中（补充病历/调查）
  - `settled`: 已结案并收到赔款
  - `rejected`: 拒赔（记录拒赔原因，支持申诉复议）
  - `cancelled`: 用户撤案
* `financials`: 财务结算明细
  - `totalMedicalExpense`: 医院总花费
  - `socialSecurityPaid`: 医保统筹及大病报销金额
  - `deductibleAmount`: 免赔额扣除
  - `claimedAmount`: 申请理赔金额
  - `settledAmount`: 最终实际获赔到账金额
  - `outOfPocket`: 最终家庭净自费金额
* `timeline`: 状态流转时间轴（报案时间、交单时间、结案时间、到账时间）
* `documents`: 发票、病历、费用清单、理赔决定书等拍照与扫描件附件

## 3. 就医与理赔智能向导 (Smart Claims Guide)

1. **出险报案一键通道**：
   - 勾选成员与险种后，自动列出报案电话、微信小程序在线报案入口；
   - 自动生成报案文本模板（包含保单号、被保人身份证号、就诊医院）。
2. **多保单报销顺序优化建议（理赔最大化）**：
   - 第一步：医保结算（保留医保分割单原件）；
   - 第二步：0 免赔小额意外险/门诊险先报销，抵扣后续百万医疗险的 1 万元免赔额；
   - 第三步：百万医疗险 100% 报销剩余大额自费部分；
   - 第四步：若涉及重疾/定额给付险，提交诊断证明直接申请现金理赔（不冲突，叠加赔付）。
3. **就医防坑与单据收集核对清单 (Checklist)**：
   - [ ] 门诊病历本原件 / 住院病案首页及出院小结（需盖病案室公章）
   - [ ] 医疗收费票据（电子发票或纸质发票原件）
   - [ ] 住院费用总清单（逐日明细汇总）
   - [ ] 医保结算凭证 / 分割单
   - [ ] 检查报告单（CT、核磁、病理切片活检报告）
   - [ ] 银行卡卡号及开户行信息（用于收款）

## 4. 统计分析与历史赔付看板 (Claims Dashboard)

* **累计获赔总额**：直观展示系统累计帮助家庭报销到账多少元（如“已累计获赔 ¥48,500”）。
* **自费率与杠杆分析**：计算家庭大病综合报销比例（如“总支出 6 万元，医保+商保覆盖 92%”）。
* **保司理赔时效评价**：记录各家保险公司的结案平均工作日（平安、人保、泰康等），为家庭后续续保决策提供真实依据。

## 5. 后续演进路线
- **Phase 1**：设计并上线 Claims 台账数据表与基础增删改查。
- **Phase 2**：在就医应急专区接入“出险一键建单”，联动现有保单与保单号。
- **Phase 3**：发票 OCR 识别与单据自动汇总（支持手机拍照发票自动提取金额）。
