# 家庭保险资产管理系统 (Family Insurance Vault)

现代化、私密安全、支持 Docker 容器化与本地极简双模运行的家庭商业保险管理系统。

---

## ✨ 核心功能

- **📊 保障总览**：年度保费统计、历年缴费趋势图、家庭成员保费占比。
- **📋 保单管理**：人身险与车险统一管理，支持状态筛选、信息编辑与新增。
- **📅 缴费日历**：按月份展示扣费时间线，支持导出 `.ics` 手机日历订阅（提前 3 天提醒）。
- **🏥 就医理赔卡**：一键查阅免赔额、报销范围及各大险企官方报案电话。
- **🔒 私密门禁**：支持一键开启访问密码与毛玻璃锁屏门禁，保护全家隐私。
- **🛡️ 安全落盘**：数据本地存储，支持原子写入与自动多版本快照备份。

---

## 🚀 快速启动

### 1. 本地运行（个人/家庭日常使用）
- **Mac**：双击运行根目录的 `start.command`
- **Windows**：双击运行根目录的 `start.bat`
- **终端命令行**：执行 `python3 backend/main.py`（默认端口 `8088`）

### 2. Docker / NAS 部署（私有云 / 群晖 / 威联通）
```bash
cp .env.example .env     # 可选：配置密码与端口
docker compose up -d     # 启动容器
```
> 访问地址：`http://localhost:8088`（局域网亦可通过设备 IP 访问）。  
> NAS 用户仅需持久化挂载 `./data` 目录至容器内 `/app/data`。

---

## ⚙️ 环境配置 (.env)

复制 `.env.example` 为 `.env` 即可按需自定义：

| 配置项 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `ACCESS_PASSWORD` | *(留空)* | 访问密码。留空即为**免密模式**；设置后自动开启**门禁锁屏鉴权**。 |
| `PORT` | `8088` | 服务监听端口。 |

---

## 📁 数据与备份

- `data/policies.json`：人身险有效与历史保单数据
- `data/history_payments.json`：历年缴费流水明细
- `data/vehicles.json`：车辆信息与车险保单
- `data/backups/`：每次保存自动保留最近 10 次快照，杜绝误伤与损坏
